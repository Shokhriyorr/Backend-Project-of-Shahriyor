DeployRocks: "Deploy the app first before setting environment variables"
======================================================================

This is NORMAL. The dashboard unlocks Environment only AFTER the first deploy.

CRITICAL - Compose file on DeployRocks:
  Set deploy branch to: deployrocks-root-dockerfile
  Leave the Compose file field EMPTY.
  DeployRocks must build the root Dockerfile only.
  Do NOT deploy main on DeployRocks right now; main contains mandatory docker-compose.yml
  for grading and DeployRocks turns it into broken api/worker/frontend apps.

ORDER (do exactly this):

STEP 1 - Deploy WITHOUT Environment tab
  - Do NOT open Environment yet (it will show that message).
  - Click: Deploy now / Retry deploy.
  - Wait until status is Live (or Failed - read Logs, fix compose field, retry).

STEP 2 - THEN set Environment
  - After first deploy attempt, open tab Environment.
  - Paste everything from: deployrocks.env.local
  - Fix PASSWORD_RESET_TTL_MINUTES = 30 (only digits).

STEP 3 - Deploy again
  - Click Retry deploy so new variables apply.

Check (after DeployRocks Live + domain assigned):
  https://YOUR-DOMAIN/health
  https://YOUR-DOMAIN/docs
