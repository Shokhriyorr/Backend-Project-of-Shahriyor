ШАГ 2 — DeployRocks: режим Dockerfile (без Compose file)
───────────────────────────────────────────────────────────────

1. https://dashboard.deployrocks.com
2. Проект → Settings
3. Поле "Compose file" — выберите ОДНО из двух:
     compose.deployrocks.yaml   (один контейнер web)
   ИЛИ оставьте ПУСТЫМ (только корневой Dockerfile)
   НЕ используйте docker-compose.yml на DeployRocks — платформа
   создаст 6 отдельных apps (api, worker, frontend, db...) и упадёт.
4. Деплой идёт из корневого Dockerfile (frontend + API + worker в одном контейнере)

Подробно: docs/deployment/deployrocks-fix.md

Локально для рубрики (экзаменатор может проверить):

  cp .env.example .env
  docker compose up --build

───────────────────────────────────────────────────────────────
ШАГ 3 — Удалить лишние приложения
───────────────────────────────────────────────────────────────

  ...-worker
