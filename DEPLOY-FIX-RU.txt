  ИСПРАВЛЕНИЕ ОШИБОК DEPLOYROCKS (по вашим логам)
═══════════════════════════════════════════════════════════════

У вас 3 ошибки:

  A) Деплоится WORKER — он не сайт → "No web listeners"
  B) Сеть ...-net does not exist → api/frontend падают
  C) Используется не тот compose (3 приложения вместо 2)

───────────────────────────────────────────────────────────────
ШАГ 1 — Запушить исправления в GitHub (на компьютере)
───────────────────────────────────────────────────────────────

Откройте PowerShell:

  cd C:\Users\Shokh\Desktop\PROJECT
  git add .
  git status
  git commit -m "Fix DeployRocks: dokku PORT, compose without worker"
  git push

Без push платформа собирает старый код.

───────────────────────────────────────────────────────────────
ШАГ 2 — DeployRocks: правильный Compose file
───────────────────────────────────────────────────────────────

1. https://dashboard.deployrocks.com
2. Ваш проект → Settings (Настройки)
3. Поле "Compose file" — ДОЛЖНО БЫТЬ ТОЧНО:

     compose.deployrocks.yaml

   НЕ docker-compose.yml
   НЕ docker-compose.local.yml

4. Save / Сохранить

───────────────────────────────────────────────────────────────
ШАГ 3 — УДАЛИТЬ приложение WORKER (обязательно!)
───────────────────────────────────────────────────────────────

В списке Apps / Applications найдите:

  shokhriyorr-backend-project-of-shahriyor-worker

→ Delete / Destroy / Remove (удалить полностью)

Worker НЕ нужен отдельно. Очереди работают внутри api.

Если есть ДВА одинаковых api или frontend — удалите лишние
(оставьте по одному api и одному frontend).

───────────────────────────────────────────────────────────────
ШАГ 4 — Environment (переменные) — только ЧИСЛА для TTL
───────────────────────────────────────────────────────────────

В Environment проекта задайте ВРУЧНУЮ (не оставляйте случайные строки):

  EMAIL_VERIFICATION_TTL_MINUTES=1440
  PASSWORD_RESET_TTL_MINUTES=30
  STATS_JOB_REPEAT_MS=900000
  JWT_ACCESS_TTL_SECONDS=900
  JWT_REFRESH_TTL_DAYS=30

  START_WORKERS_IN_API=true
  ENABLE_BACKGROUND_WORKERS=true
  EMAIL_PROVIDER=smtp

  JWT_SECRET_KEY=<ваш секрет 32+ символа>
  JWT_REFRESH_SECRET_KEY=<другой секрет 32+ символа>
  SMTP_PASS=<ключ SendGrid/Mailgun>
  EMAIL_FROM_ADDRESS=Academy Portal <ваш@email.com>

  PUBLIC_APP_URL=https://shokhriyorr-backend-project-of-shahriyor.kazi.rocks
  CORS_ORIGINS=https://shokhriyorr-backend-project-of-shahriyor.kazi.rocks

Сгенерировать JWT:

  powershell -ExecutionPolicy Bypass -File scripts\generate-deploy-secrets.ps1

DATABASE_URL и REDIS_URL — НЕ трогать, если платформа уже подставила.

───────────────────────────────────────────────────────────────
ШАГ 5 — Проверить Postgres и Redis
───────────────────────────────────────────────────────────────

В проекте должны быть зелёные:

  ...-db (postgres)
  ...-redis (redis)

Если красные — дождитесь или пересоздайте плагины, потом шаг 6.

───────────────────────────────────────────────────────────────
ШАГ 6 — Deploy снова (2 раза если нужно)
───────────────────────────────────────────────────────────────

1. Нажмите Deploy / Retry deploy
2. Должно быть только 2 приложения: api + frontend (НЕ worker)
3. Если снова "Network ... does not exist" — подождите 1 минуту
   и нажмите Retry deploy ЕЩЁ РАЗ (сеть часто создаётся после 1-й попытки)

Успех:

  Deployed (2): api, frontend
