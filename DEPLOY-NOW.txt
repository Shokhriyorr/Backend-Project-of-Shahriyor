Academy Portal - DeployRocks (5 minutes)
=======================================

1) Open https://dashboard.deployrocks.com -> your project -> Settings

2) Compose file (IMPORTANT - not docker-compose.yml):

   compose.deployrocks.yaml

3) Environment -> paste from deployrocks.env.example
   Replace SMTP_PASS, JWT_SECRET_KEY, JWT_REFRESH_SECRET_KEY.
   Generate JWT:
     powershell -ExecutionPolicy Bypass -File scripts/generate-deploy-secrets.ps1

   Set PUBLIC_APP_URL and CORS_ORIGINS to your live domain, e.g.:
     https://shokhriyorr-backend-project-of-shahriyor.kazi.rocks

   Do NOT override DATABASE_URL / REDIS_URL unless the dashboard shows them empty.

4) Remove failed separate "worker" app if it exists (workers run inside api).

5) Retry deploy -> wait until api + frontend = Live

6) Smoke test (same host as frontend):

   https://YOUR-DOMAIN.kazi.rocks/health
   https://YOUR-DOMAIN.kazi.rocks/docs
   https://YOUR-DOMAIN.kazi.rocks/api/courses

7) Put the frontend URL (first line only) in DEPLOYED_URL.txt -> git push

8) Record defense video -> VIDEO_LINK.txt -> git push
